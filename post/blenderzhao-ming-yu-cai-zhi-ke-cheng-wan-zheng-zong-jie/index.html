Blender照明与材质课程完整总结

Blender · 2026-09-06 · 9 分钟阅读

Blender 3D 设计：照明与材质效果 · 完整课程总结

课程：Blender 3D Design Lighting and Materials（照明与材质效果视频教程）
讲师：Derek Elliott（3D Blender 产品动画师）
共 8 节课，合计约 48 分钟。字幕来源：本教程 8 个 .srt 字幕文件。

课程概览

本课程从零开始讲解 Blender 中「照明」与「材质」两大核心模块，走通一条完整的工作流：

照明（Lighting）→ 材质（Materials）→ 纹理（Textures）→ 渲染出图（Render）

学完后你将能够：用 HDRI 和 2~3 盏灯打出专业场景光；用 Principled BSDF 做出金属、玻璃、皮肤/橡胶等真实材质；用程序纹理和图像纹理为表面添加细节；最后用正确的渲染设置输出高质量作品。

第 1 课：课程介绍（Introduction，约 1 分 40 秒）

  • 讲师自我介绍：Derek Elliott，长期用 Blender 制作产品动画。
  • 为什么照明和材质重要：想在 ArtStation、Behance 等平台接自由职业或被推荐作品，优秀的照明和材质是关键路径。
  • 破除误区：那些"超写实"材质往往只是加了几张贴图，不是花了几个小时。
  • 课程预告：HDRI 及其旋转、区域光、灯光颜色、金属材质、透射材质（玻璃）、次表面散射（皮肤/橡胶）、高效率渲染设置。

第 2 课：发现灯光工具（Discover Lighting Tools，约 6 分 10 秒）

准备工作：下载最新版 Blender；准备好键盘鼠标；场景里放一个待照明的物体。分割视口，一侧设为渲染视图。

为什么没有灯也能看见物体：因为默认「世界背景」是灰色的。把世界颜色改为黑色或把强度降到 0，场景就会真正变黑。

灯光类型（Shift+A → 灯光）：

灯光 特点 用法要点
点光 Point 向四周均匀发光 拖动围绕物体观察光影变化；初学者渲染太暗时"不用担心电费"，把功率调高
区域光 Area 讲师最爱，光线柔和 投射面积大，能被场景中的平面反弹照明
天空纹理 Sky 场景照明利器 调"海拔"控制太阳角度，“旋转"让太阳绕物体移动，从而控制阴影方向
HDRI 环境贴图 高动态范围图像，一次提供完整环境光 在 World 设置中把 Nishita 天空换成 Environment Texture；节点变粉红 = 贴图丢失

自发光材质：给一个网格（如圆环+皮肤修改器）换成 Emission 发射着色器，网格自身就会发光，是新手把"真实光线"带进场景的好方法（讲师旧时最爱）。

HDRI 实操：

  • 免费资源站：Poly Haven（polyhaven.com），高清、免费。
  • 旋转 HDRI：先安装 Node Wrangler 插件（编辑 → 偏好设置 → 插件 → 搜索并启用），在着色器编辑器里把模式从"物体"切到"世界”，选中 HDRI 后按 Ctrl+T 自动生成"纹理坐标 + 映射"节点，改 Z 旋转值即可转动天空。
  • HDRI 特别适合给金属物体带来独特的环境反射。

核心理念：不需要懂背后所有科学原理，Blender 的工作方式就是"拖滑块看效果"。

第 3 课：学会用光（Learn How To Use Light，约 5 分 22 秒）

本课讲照明理论：用光营造氛围、引导视线到物体特定部位。实例：一只耳机模型（讲师自由职业项目）。

经典三步布光法：

  1. 边缘光（Rim Light）：区域光放物体后方，勾勒轮廓。注意把灯光尺寸缩到与物体比例相称，否则边缘会过曝。
  2. 补光（Fill Light）：复制一盏灯放前方/侧方，提供背景信息，避免暗部死黑看不到细节。
  3. 形态光：再加一盏灯，让物体形态和材质质感真正显现（橡胶部分 vs 金属部分）。必要时把灯移到物体下方，补足底部细节。

真实色温：选中灯光后用着色器节点（Shift+A → 转换器 → 黑体 Blackbody）控制色温——暖光约 3500K，冷光约 7500K。暖光放底部、冷光放顶部，渲染更有活力。节点可用 Ctrl+C / Ctrl+V 复制粘贴到另一盏灯。

强调局部细节：不要用整盏灯照亮全部；把灯缩小并贴近目标区域；区域光的"扩散（Spread）“值调低会形成聚光效果；形状可从正方形改为长方形。

练习方法与心法：

  • 拿一个物体，从一盏灯开始，移动它找有趣的阴影，再慢慢加灯。
  • 最大进步来自"用最少的灯”：动画/产品照明通常 2~3 盏就够。
  • 灯在物体侧面或后方往往比正面更出效果；正面灯太多会毁掉渲染。

第 4 课：理解材质基础（Understand Material Basics，约 8 分 41 秒）

重要前提：透射等材质在 Cycles 渲染引擎下才正常（Eevee 效果差）；有 GPU 就在渲染设置里选 GPU。先布好一个已知的光照环境，才能看清材质。

默认新材质 = Principled BSDF 主着色器，核心参数逐一讲解：

参数 作用 要点
颜色 Color 物体基础色 直观
粗糙度 Roughness 0 = 光滑闪亮，1 = 粗糙哑光 控制材质质感最常用的滑杆
金属度 Metallic 0 = 非金属，1 = 金属 拉满即出现金色金属质感；做金材质建议用低饱和度颜色更真实
透射 Transmission 1 = 光穿透，变成玻璃 只在 Cycles 有效；金属度=1 时透射失效，需先归零；调低颜色饱和度做有色玻璃；配合粗糙度做磨砂玻璃；“透射粗糙度"可做外表面光滑、内部雾化的效果
光泽 Sheen 表面微绒毛感 拉高（如 60）出现天鹅绒质感，适合塑料
透明涂层 Clearcoat 第二层粗糙度 金属漆 + 低粗糙度清漆层 = 汽车漆效果
次表面散射 Subsurface 光穿透并在内部散射 做皮肤、蜡、橡胶；例如角色耳后透光；数值取决于物体比例
IOR 折射率 光穿过时的折射程度 做超写实玻璃/塑料可上网查各材质折射率表

练习建议：在现实世界找材料，用这些滑块尝试复刻。

第 5 课：使用程序纹理（Use Procedural Textures，约 8 分钟）

什么是程序纹理：由数学定义、内置在 Blender 中，无需下载图片文件，就能给基础着色器增加细节层次。

节点工作流：按 Ctrl+T 自动添加"纹理坐标 + 映射"节点；Ctrl+Shift+左键点击任意节点即可预览效果。程序纹理建议用 Object 坐标（物体未 UV 展开时不会拉伸）。

本课实例（椅子+房间场景）：

  • Voronoi 纹理（气泡状）→ 皮革：配合"矢量 → 凹凸 Bump"节点，把 Distance 接 Height，强度压到很低；方向反了可用"反相"翻转。粗糙度相应调低一点，皮革更柔和。
  • 波浪/花岗岩纹理 → 地板：同样的 Bump 工作流，Distance 压到 0.01 级别，做出细微起伏。
  • 噪点纹理 Noise → 石膏墙：讲师用得最多；Scale 控制大小，另有细节（Detail）、粗糙度、失真（Distortion）参数。
  • 图像转凹凸 → 画作笔触：把绘画贴图颜色接到 Bump 高度，颜色会被转成黑白做凹凸，画出立体笔触。
  • 魔法纹理 Magic → 布料：把 Factor 接到 Alpha 做半透明花纹，也可再接入 Bump 增加织物质感。

进阶细节：纹理的大小必须与观察距离匹配——靠近看要调大 Scale，远离看要调小，这是"初学者 vs 高级渲染者"的分水岭。

程序纹理可以接入颜色、粗糙度、金属度、Alpha 等任何通道。

第 6 课：利用图像纹理（Utilize Image Textures，约 12 分钟）

与程序纹理的区别：图像纹理使用真实图片文件，需要 UV 贴图——想象把糖纸包在糖果上，从平面图像包裹到 3D 模型的过程叫 UV 展开。

UV 展开流程：编辑模式（Tab）→ 选中边缘线 → Ctrl+E 标记接缝（放在模型自然的位置，如边缘、底部）→ 按 U 展开 → 在 UV 编辑器调整各 UV 岛的位置/缩放/翻转（反了按 -1 缩放）→ 视口贴图模式下检查纹理方向。没有接缝也可以先用智能 UV 投射让 Blender 自动猜测。

实例 1：化妆品瓶贴标签：图像纹理接颜色出标签；同一张贴图接 Roughness 做出斑点光泽，接 Bump 做凹凸；黑白图可用"混合 Mix"节点重映射成任意颜色（黑=0 白=1）。

实例 2：椅子木纹：先用 Ctrl+A 把细分曲面、实体化等修改器全部应用，拿到基础网格再做 UV 展开；在木料自然分界处标记接缝，展开后纹理流向自然。

实例 3：PBR 石墙（写实工作流，Poly Haven 下载的贴图组）：

  • 漫反射（Diffuse） → 颜色输入
  • 粗糙度（Roughness） → 粗糙度输入；注意数据类贴图的色彩空间要改成 Non-Color（非颜色）；粗糙度贴图偏暗可能是因为来源软件用的是"光泽度"概念，需反向处理
  • 法线（Normal） → 必须经过"法线贴图 Normal Map"节点，色彩空间改 Non-Color，Strength 控制强度
  • 置换（Displacement） → 位移输入；需要右键细分网格（或加细分修改器）让几何真正变形，材质设置里把置换模式改为 “位移和凹凸 Displacement and Bump” 才会渲染出置换

结论：仅凭一个平面 + 3~4 张免费贴图，无需建模就能渲染出超写实石墙。

第 7 课：探索渲染设置（Explore Render Settings，约 5 分钟）

把前面所有纹理整合进房间场景，正式出图：

  • 多相机：复制相机得到新机位，按 Ctrl+小键盘 0 切换为活动相机视角。
  • 构图：视口叠加层 → 构图辅助线 → 三分法，把主体（椅子）放在线条/交叉点上；换个近景角度展示椅面画作与地板。
  • 色彩管理：渲染设置 → 颜色管理 → 变换（Look）调高对比度，避免画面发灰（讲师偏好高对比）。
  • 输出设置：分辨率按需设定；快速预览用 JPEG（文件小），成品用 PNG（质量更好）。
  • 采样：用 GPU 渲染；开启去噪后约 600 采样已足够，最终渲染甚至可以再低。
  • 景深（DoF）：Shift+A 添加一个 空物体 Empty（球体，重命名为 focus），移到想对焦的位置；相机属性 → 景深 → 聚焦对象选它；F-stop 别调太低，自然的虚化会突出椅子主角，同时保留石墙受光、画作和雕像的暗示。
  • 出图：按 F12 渲染 → 图像 → 另存为 PNG → 可分享到 Instagram / Facebook / Twitter / ArtStation 等平台。

第 8 课：结语（Final Thoughts，约 1 分 23 秒）

课程核心收获：

  1. 少即是多——尤其是灯光：尽量少用灯（2~3 盏），不够亮就加功率，而不是加灯。
  2. 材质灵感无处不在——用程序纹理和滑块去复刻现实中的材料。
  3. 程序纹理可以接到任何通道（颜色、粗糙度、金属度、Alpha……）。
  4. 不必在每个项目都用上所有技巧；聚焦画面质量与你想讲的故事，保持简单，做出让自己骄傲的作品。
